# hertech-studio

Лендинг IT & AI студии hertech-studio. Статический сайт (один файл `index.html`), хостинг — GitHub Pages, домен — hertech-studio.ru.

## Локальный просмотр
Открыть `index.html` в браузере (двойной клик) — сборка не требуется.

## Деплой
Хостится на GitHub Pages из ветки `main`, папка `/root`. Кастомный домен задан файлом `CNAME`.

## Файлы
- `index.html` — вся страница (HTML + CSS + JS в одном файле)
- `CNAME` — кастомный домен для GitHub Pages
- `.nojekyll` — отключает обработку Jekyll
